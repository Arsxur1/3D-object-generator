Протокол: `docs/preregistration_increment12.md` (разбиение и код анализа — `c99f469` до

## Применение решения

`prereg12.apply_decision` добавил в `configs/ml.yaml` раздел `neonatal:`: для пациентов с
указанным постменструальным возрастом **оффлайн — пороговый детектор**, **монитор —
неонатальная модель** (`ictal_gbm_realtime_neo1`, threshold 0.5, ≥ 20 эпох, Platt
`calibration.ml_realtime_neo1.json`). Общая модель v2 к новорождённым **не применяется**.
Взрослые и дети — без изменений.

## Интерпретация

* **Главный вывод — по безопасности:** общая модель v2 (дефолт после инкремента 11),
  применённая к новорождённым без обучения на них, находит лишь 35% приступов оффлайн и
  21% в мониторе — заметно хуже порогового детектора (55% и 39%). До этого инкремента
  система применила бы её и к новорождённым; теперь маршрутизация по возрасту это
  исключает. Карточка модели и раньше исключала новорождённых — проверка подтвердила, что
  ограничение необходимо.
* **Монитор:** неонатальная модель — 0.45 при 3.12 FA/ч против порогового 0.39 при 3.48:
  больше приступов при меньшем числе тревог; макро-чувствительность 0.52 против 0.23
  (пороговый монитор находит приступы лишь у части новорождённых). → неонатальная модель.
* **Оффлайн:** неонатальная модель 0.50 при 5.02 против порогового 0.55 при 4.66 — хуже по
  обоим показателям → остаётся пороговый детектор.
* **Внутренняя оценка оказалась оптимистичной:** leave-one-neonate-out на развивающей
  половине обещал 0.73 оффлайн и 0.70 в мониторе; на тестовой — 0.50 и 0.45. Пороговый
  детектор при этом перенёсся стабильно (0.58 → 0.55 оффлайн; 0.45 → 0.39 монитор).
  20 новорождённых с приступами в обучении — мало для модели; в отличие от инкрементов
  10–11 (20–31 пациент с сотнями часов) перенос не подтвердился оффлайн.
* **Абсолютный уровень низкий:** лучший детектор находит около половины консенсусных
  неонатальных приступов при 3–5 ложных тревогах/ч. Неонатальные приступы короткие,
  фокальные и часто ритмические без высокой амплитуды; для клинического применения у
  новорождённых этого недостаточно (документировано как ограничение).

## Исследовательский разбор (пост-хок)

* Вторичное: если не считать ложными детекции в зонах, отмеченных одним-двумя экспертами,
  FA/ч снижаются на 0.4–1.1 (таблица выше) — часть «ложных» тревог приходится на спорные
  эпизоды.
* Новорождённые без консенсусных приступов (20): FA/ч оффлайн — пороговый 5.64,
  неонатальная 5.75, v2 3.56; монитор — 3.97, 3.75, 1.89. Низкие тревоги v2 — следствие
  низкой чувствительности, а не специфичности.

## Отклонения исполнения (не анализа)

* Файл `eeg50.edf` (MD5 совпадает с Zenodo) объявлен как EDF+C без обязательного
  сигнала аннотаций; pyedflib отказался его читать, первый запуск оценки остановился до
  получения каких-либо метрик. Добавлено чтение «простого» EDF (`PlainEdfReader`,
  совпадение с pyedflib до 1e-12, тест), оценка перезапущена; анализ не менялся.

## Что дальше

* Неонатальная модель для оффлайн-анализа требует больше данных (вся развивающая и
  тестовая половины уже использованы); следующий набор новорождённых — новая
  пре-регистрация.
* Морфологические неонатальные признаки (ритмические разряды низкой амплитуды,
  эволюция частоты) — кандидаты для обучения на развивающей половине.
