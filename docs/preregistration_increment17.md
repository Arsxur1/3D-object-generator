# Пре-регистрация, инкремент 17: заключение «норма / отклонения» на рутинной ЭЭГ (NMT)

> Зафиксировано и опубликовано **до** запуска любого пайплайна (нового или старого) на
> оценочной части NMT. Все исправления разработаны только на подвыборке **обучающей** части
> авторов набора (seed 17: 120 нормальных + 80 аномальных записей).

## 1. Вопрос и что было найдено

Все предыдущие проверки касались отдельных детекторов на данных с приступами (CHB-MIT, Siena,
Helsinki). Главный вопрос рутинной ЭЭГ — **называет ли система нормальную запись нормальной** —
не проверялся. NMT (Khan et al. 2022; Zenodo 10.5281/zenodo.10909103, CC BY 4.0): 2 417 рутинных
ЭЭГ, каждая размечена бригадой неврологов как normal/abnormal, возраст и пол; разбиение авторов
train/eval. Набор читается по HTTP-диапазонам; нумерация не совпадает с NMT-Events (метки и
возраст расходятся), побайтно одинаковых EDF нет, в выборке из 25 пар одинакового размера
одинаковых сигналов нет. 30 записей, у которых класс в Labels.csv не совпадает с каталогом,
исключены (все в обучающей части).

На обучающей подвыборке исходный пайплайн дал **специфичность 0.00**: все 120 нормальных записей
получили «картина отклонений». Срабатывания в нормальных записях: эвристические спайки 100%,
обученный детектор приступов 89%, GRDA 88%, LPDs 72%, вспышка-подавление 64%, FIRDA 59%,
диффузное замедление 54%, фокальное 39%, трёхфазные волны 35%.

## 2. Исправления (каждое — по определению ACNS / явной ошибке; тесты в `tests/test_routine.py`)

| # | Что | Причина ложных срабатываний | Исправление |
|---|---|---|---|
| F1 | вспышка-подавление | «огибающая» = среднее |x| (≈ 0.32 × размаха) → < 10 мкВ принимало ~30 мкВ; эпизод оценивался по **среднему каналов** (≈ 0 после среднего референта) | ACNS: размах < 10 мкВ на медианном канале; эпизод — по маскам каналов |
| F2 | GRDA/LRDA | «ритмичность» = доминантная частота в дельте и ≥ 40% мощности у пика — выполняется для обычного 1/f-фона; «генерализация» из прогонов разных минут | автокорреляция дельта-полосы на одном периоде ≥ 0.7 (окна 6 с), каналы **одновременно** |
| F3 | LPDs/GPDs/BIPDs | 6 «острых» пиков на **одном** канале с похожими интервалами | разряды синхронны на ≥ 2 каналах (± 50 мс); ≥ 10 с (ACNS: короче — «очень короткие»); LPDs — ≥ 2 латеральных канала |
| F4 | заключение | непроверенные кандидаты-спайки и события приступа с калиброванной вероятностью 0.03–0.5 делали запись «патологической» | уровень «сомнительно»: называются в заключении как находки для просмотра; спайк — патологичен только при вероятности обученной модели ≥ 0.95 |
| F5 | ЗДР / диффузное замедление | максимум спектра 4–13 Гц на 1/f-фоне = 4 Гц → «замедление» | ЗДР — только реальный пик ≥ 2× фона 1/f, иначе «не выделен»; замедление без Fp1/Fp2/F7/F8 (движения глаз) и ушных |
| F6 | фокальное замедление | отношение абсолютной мощности за всю запись — одного «шумного» электрода достаточно | устойчивая (медиана по эпохам, один знак ≥ 70%) разница **относительной** медленной мощности ≥ 0.25 |
| F7 | FIRDA | тот же спектральный тест | автокорреляция (окна 3 с), обязательны F3/F4/Fz |
| F8 | трёхфазные волны | чисто спектральный признак | ACNS 2021: «GPDs с трёхфазной морфологией» → только вместе с GPDs |
| F9 | возрастные нормы | нет полосы < 1 года и дыра между полосами (5.5 лет → взрослые нормы) | полосы младенец/1–2 года, непрерывный выбор; у детей < 6 лет без ЗДР замедление — «сомнительно» |
| F10 | граф причин | механизм «замедление → энцефалопатия» оставался патологическим, когда само замедление признано нормой для возраста | механизм не может быть увереннее своих событий |

Траектория на обучающей подвыборке (`out_eval/routine_diagnose_v0..v4.json`):

| Версия | Специфичность | Чувствительность |
|---|---|---|
| исходная | 0.000 | 1.000 |
| F1–F2 | 0.042 | 1.000 |
| + F3–F8 | 0.333 | 0.963 |
| + F9 | 0.333 | 0.963 |
| + F10 (заморожено) | **0.575** | **0.800** |

Пороги — из определений ACNS или округлённые значения; подбора по оценочной части не было.
Оставшиеся причины «отклонений» у нормальных (обучение): диффузное замедление 0.14, спайк с
вероятностью ≥ 0.95 0.12, LPDs 0.07, приступ (калибр. ≥ 0.5) 0.07, BIPDs 0.05.

## 3. Проверка (оценочная часть авторов: 95 нормальных, 90 аномальных; конфликтов меток нет)

Оба пайплайна запускаются на одних и тех же записях с возрастом из Labels.csv и поправкой единиц
×100 (D43): **новый** (этот коммит) и **старый** — коммит 4519669 (последний до исправлений).
«Заключение аномально» = в графе есть хотя бы один патологический узел.

## 4. Гипотезы (`evaluation/prereg17.py`)

* **H1** — специфичность нового ≥ **0.45**.
* **H2** — прирост специфичности против старого ≥ **0.30** (те же записи).
* **H3** — чувствительность нового ≥ **0.70**.
* **H4** (вторичная) — срабатывания в нормальных: вспышка-подавление ≤ 0.05, GRDA ≤ 0.05, LPDs ≤
  0.15, трёхфазные ≤ 0.05, FIRDA ≤ 0.15.

## 5. Правило решения (`prereg17.apply_decision` → `configs/impression.yaml`)

* **H1 ∧ H2 ∧ H3** → `routine_validated: true` с измеренными специфичностью и чувствительностью:
  заключение сопровождается фразой с этими числами; режим B больше не блокируется этим условием.
* Иначе → `routine_validated: false`: заключение сопровождается фразой «автоматическое разделение
  “норма/отклонения” на рутинной ЭЭГ не прошло проверку — заключение формирует врач», режим B
  заблокирован. (Это состояние уже включено по умолчанию до проверки.)
* Исправления F1–F10 остаются в любом случае: это исправления определений и ошибок, а не
  настройка; их влияние на ранее проверенные показатели (приступы, сон) проверяется отдельно.

## 6. Воспроизведение

```bash
neurolens routine diagnose --workers 5                     # обучающая подвыборка
# --- граница пре-регистрации ---
neurolens routine eval --out docs/increment17_metrics_new.json
git worktree add ../old 4519669 && (cd ../old && neurolens routine eval --cache <data/nmt> --out ...old.json)
```

## 7. Ограничения, известные заранее

* Метка — на уровне записи; какие именно отклонения в аномальных записях — неизвестно.
* Один центр/прибор; поправка единиц выведена из уровня сигнала (D43).
* FIRDA после исправления не сработала ни разу на обучении — её чувствительность неизвестна.
* Влияние F1–F10 на показатели прошлых инкрементов (приступы CHB-MIT/Siena, неонатальные) этой
  проверкой не оценивается; обученный детектор приступов не менялся.
