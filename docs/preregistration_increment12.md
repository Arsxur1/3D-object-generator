# Пре-регистрация: инкремент 12 — выявление приступов у новорождённых (Helsinki)

> Зафиксировано в git **до загрузки любой ЭЭГ новорождённых**. Загружены только таблица
> клинических данных и разметка экспертов (по ним задано разбиение). Разбиение, эталон,
> кандидаты, правило выбора модели, гипотезы, правила решения и код анализа
> (`evaluation/prereg12.py`) не меняются после получения результатов; замороженные модели
> добавляются в раздел «Заморожено» до загрузки тестовой половины.

## Вопрос

Детекторы NeuroLens обучены и проверены на детях от 1.5 лет и взрослых (CHB-MIT, Siena);
карточка модели прямо исключает новорождённых. ТЗ (§1, §6) требует неонатальной
специализации. Вопросы:

1. Как общая модель v2 (дефолт после инкремента 11) и пороговый детектор работают у
   новорождённых **без обучения на них**?
2. Улучшает ли выявление модель, обученная на новорождённых (развивающая половина
   набора), на **других** новорождённых (тестовая половина)?
3. Какой детектор система должна применять к новорождённым (пациент с указанным
   постменструальным возрастом) — оффлайн и в мониторе?

## Данные

Stevenson N.J. et al., *A dataset of neonatal EEG recordings with seizure annotations*,
Scientific Data 6:190039 (2019); Zenodo 10.5281/zenodo.2547147, CC BY 4.0. 79 доношенных
новорождённых (ОРИТН, Helsinki University Hospital), по одной записи (медиана 74 мин, всего
113.5 ч), 256 Гц, 19 электродов 10-20. Разметка трёх экспертов посекундно. Целостность —
MD5 из записи Zenodo (`datasets/helsinki.HelsinkiClient`).

## Эталон (зафиксировано)

* Приступ — **консенсус**: секунды, отмеченные всеми тремя экспертами; непрерывные серии
  длительностью **≥ 10 с** (определение неонатального приступа); без склейки серий.
* Секунды, отмеченные одним-двумя экспертами, — «неоднозначные» зоны: не считаются
  приступами; во вторичном анализе детекции в них не считаются ложными тревогами.
* Оценка событий — как в инкрементах 9–11 (OVLP: детекция, пересекающая [начало − 30 с,
  конец + 60 с], — найденный приступ; детекции, разделённые < 10 с, объединяются;
  остальные — ложные тревоги; FA/ч на всю длительность записи).

## Неонатальная модель (обучение — только развивающая половина)

* Признаки — набор v1 (23 каузальных признака), бустинг — те же настройки (200 итераций,
  31 лист, balanced, random_state 0); отдельные модели оффлайн и для монитора.
* **Кандидаты:** (N) только новорождённые развивающей половины; (C) 31 обучающий пациент
  инкрементов 8–11 + новорождённые развивающей половины.
* **Выбор кандидата и рабочей точки A** — leave-one-neonate-out на развивающей половине
  (в варианте C старшие пациенты всегда в обучении): максимальная чувствительность при
  FA/ч не больше, чем у порогового детектора **на тех же данных** (оффлайн и монитор
  отдельно); при равенстве — меньше FA/ч; из двух кандидатов — с большей чувствительностью
  в своей точке A (при равенстве — меньше FA/ч). Если ни одна точка сетки не укладывается
  в бюджет — точка с минимальным FA/ч. Сетка — как в инкременте 11.
* Калибровка Platt — по событиям LOSO в точке A (как в инкременте 11).

## Сравнение на тестовой половине

Пороговый детектор (дефолт), общая модель v2 (инкремент 11, точка A, режим `*-cmp-A`),
неонатальная модель (точка A, режим `*-ml-A`) — оффлайн и в мониторе:

```bash
neurolens physionet fetch --db helsinki --subjects test --max-gb 3
neurolens ml-eval --db helsinki --test test \
  --frozen docs/preregistration_increment12_frozen.json \
  --compare docs/preregistration_increment11_frozen.json \
  --assess --analysis prereg12 --out out_eval/prereg12
```

## Гипотезы («не хуже» = чувствительность ≥ пороговой − 0.05 **и** FA/ч ≤ порогового)

* **H1 (первичная):** неонатальная модель оффлайн не хуже порогового детектора.
* **H2:** неонатальная модель в мониторе не хуже порогового монитора.
* **H3:** общая модель v2 оффлайн не хуже порогового (перенос без обучения).
* **H4:** общая модель v2 в мониторе не хуже порогового.

## Правила решения (для каждого пути отдельно, `prereg12.choose`)

* Неонатальная модель — если она не хуже порогового **и** (общая модель не проходит
  либо неонатальная не хуже общей); иначе общая модель — если она не хуже порогового;
  иначе — **пороговый детектор**.
* Применение — `prereg12.apply_decision`: пишет раздел `neonatal:` в `configs/ml.yaml`
  (`general` / `threshold` / `neonatal` + параметры модели); общие разделы не меняются.
  Пайплайн и монитор применяют его к пациентам с указанным постменструальным возрастом.
* Вторичные (не меняют решения): макро-чувствительность по новорождённым; FA/ч без
  детекций в неоднозначных зонах; неонатальная против общей.

1. Этот документ и код анализа фиксируются в git (тестовая ЭЭГ не загружена).
2. Загружается развивающая половина; строятся признаки и потоки монитора; LOSO
