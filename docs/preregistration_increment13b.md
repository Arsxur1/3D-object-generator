# Пре-регистрация: инкремент 13b — перенос стадировщика сна на клиническую ПСГ (CAP)

> Зафиксировано в git **до загрузки сигналов** CAP Sleep Database. Прочитаны только
> заголовки EDF (метки каналов — HTTP-запросы первых 16 КБ) для правила отбора. Модель —
> замороженная в инкременте 13 (`configs/models/sleep_stager_v1.json`, SHA-256 в
> `docs/preregistration_increment13_frozen.json`), **без дообучения**. Код анализа —
> `evaluation/prereg13b.py`.

## Вопрос

Стадировщик проверен на ПСГ здоровых взрослых с отведениями Fpz-Cz / Pz-Oz. В клинических
записях таких отведений обычно нет; без центральной линии пайплайн сейчас не стадирует. Можно
ли включить приближение по парасагиттальной цепочке (Fp2−C4 вместо Fpz−Cz, P4−O2 вместо
Pz−Oz) для пациентов с нарушениями сна?

## Данные и отбор (зафиксировано, `datasets/capsleep.select_records`)

CAP Sleep Database (PhysioNet capslpdb 1.0.0): 108 клинических ПСГ (здоровые и пациенты:
ночная лобная эпилепсия, нарушение поведения в фазе REM, периодические движения конечностей,
инсомния, нарколепсия, нарушения дыхания во сне, бруксизм), гипнограммы R&K (30 с).

Правило: записи с цепочкой Fp2-F4, F4-C4, P4-O2 (или левой Fp1-F3, F3-C3, P3-O1) и каналом
ROC-LOC; из каждой группы — первые 4 по номеру. Итого **29 записей**: n2, n3, n5, n10; brux1,
brux2; ins1–4; narco1–4; nfle1–4; plm1–4; rbd1–4; sdb1, sdb2, sdb4.

## Производные и эталон

* Fpz-Cz ≈ (Fp2-F4) + (F4-C4) = Fp2−C4; Pz-Oz ≈ P4-O2; ЭОГ ≈ ROC-LOC (левая цепочка,
  если правой нет); передискретизация в 100 Гц.
* R&K → AASM (S3+S4 → N3; MT, «unscored» не оцениваются); окно — сон ± 30 мин; время
  стадий по часам из файла разметки относительно начала EDF.

## Гипотезы и правило решения

* **H1:** каппа на 29 записях ≥ 0.60 (порог ниже, чем в инкременте 13: иные производные,
  приборы и пациенты).
* **H2:** каппа ≥ каппы правилового стадировщика + 0.10.
* Решение: `configs/sleep.yaml parasagittal_fallback: true`, если верны H1 и H2; иначе
  `false` (записи без центральной линии не стадируются). Применение —
  `prereg13b.apply_decision`.
* Вторичное: каппа по диагностическим группам (без решений).

```bash
neurolens sleep cap --assess --out out_eval/prereg13b
```

Загрузка: каждая запись скачивается, превращается в признаки и удаляется (место на диске).
