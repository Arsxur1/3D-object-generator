# Карточка модели: обученный детектор приступов NeuroLens (`ictal_gbm_*_v2`, ранее `_v1`)

> Формат — карточка модели (model card) для технической документации и подготовки к
> регуляторной оценке (ТЗ §14–16). Метод — `docs/learned_detector.md`; проверка —
> `docs/preregistration_increment10.md`, `docs/validation_physionet.md`.

## 1. Сведения о модели

| Поле | Значение |
|---|---|
| Название | **текущие:** `ictal_gbm_offline_v2`, `ictal_gbm_realtime_v2` (инкремент 11); предыдущие: `ictal_gbm_*_v1` (инкремент 10) |
| Тип | градиентный бустинг деревьев (бинарная классификация эпох «приступ / нет») |
| Вход | 23 каузальных признака эпохи 2 с (шаг 1 с), вычисляемых NeuroLens из ЭЭГ |
| Выход | вероятность на эпоху → события «судорожная активность» (`ictal_ml`) по правилу «≥ `min_epochs` эпох со сглаженной вероятностью ≥ `threshold`» |
| Файлы | v2: `configs/models/ictal_gbm_offline_v2.json` (200 деревьев, SHA-256 `adcf1f29…`), `configs/models/ictal_gbm_realtime_v2.json` (200 деревьев, `7470b577…`); v1: `…_offline_v1.json` (`e74576ab…`), `…_realtime_v1.json` (`9591cb9a…`) |
| Формат | JSON (узлы деревьев); исполнение numpy; без pickle и исполняемого кода |
| Обучение | scikit-learn `HistGradientBoostingClassifier` (200 итераций, ≤31 лист, lr 0.1, class_weight balanced, random_state 0) |
| Рабочие точки (A) | v2: оффлайн threshold 0.3, ≥ 15 эпох; монитор 0.7, ≥ 5 эпох (v1: 0.4/5 и 0.3/15) |
| Калибровка | Platt v2: `configs/calibration.ml_offline_v2.json`, `configs/calibration.ml_realtime_v2.json` (v1: `calibration.ml_{offline,realtime}.json`) |
| Версия кода | признаки — `neurolens.layer4_detect.ml_ictal` v1 (feature set 1) |
| Дата заморозки | v2: 2026-10-05 (коммит `23e7bcc`); v1: 2026-10-02 (`389c390`) |

## 2. Назначение

* **Предназначение:** поддержка решений — выделение участков ЭЭГ, подозрительных на
  судорожную активность, для просмотра нейрофизиологом / реаниматологом: в отчёте
  оффлайн-анализа и как тревога в потоковом мониторинге (cEEG).
* **Пользователи:** обученный медицинский персонал (режим A — обязательная проверка
  врачом).
* **Не предназначено для:** автономной постановки диагноза; принятия решений без
  врача; новорождённых (не обучалось на неонатальных данных); внутричерепной ЭЭГ;
  записей вне 10-20 / с < ~16 скальповых отведений (не проверялось).

## 3. Данные обучения

* Открытые экспертно-размеченные базы PhysioNet: **CHB-MIT** (дети, 256 Гц, биполярные
  отведения → восстановленная средняя референция) и **Siena** (взрослые с фокальными
  височными приступами, 512 Гц, референциальные).
* v2: **31 пациент** (22 CHB-MIT, 9 Siena), 228 записей, 322 ч, 208 приступов.
* v1: 20 пациентов (14 CHB-MIT, 6 Siena), 142 записи, 151.6 ч, 100 приступов; 545 764 эпохи.
* Разметка: эпохи внутри экспертного интервала приступа — 1; ±зона неоднозначности
  (−30 с / +60 с) исключена; остальное — 0.
* Демографическое покрытие ограничено: преимущественно дети 2–19 лет и взрослые 20–71;
  типы приступов — представленные в CHB-MIT и фокальные височные (Siena).

## 4. Качество

**Внутренняя проверка v2 (leave-one-subject-out, 31 пациент, 208 приступов):** оффлайн A —
0.918 при 6.94 FA/ч (пороговый 0.880 при 9.62); монитор A — 0.861 при 3.72 FA/ч (пороговый
0.827 при 3.76). Доля истинных событий в точке A: 8.5% оффлайн, 16% монитор.

**Внутренняя проверка v1 (leave-one-subject-out, 20 пациентов):**

| Путь | Рабочая точка | Чувствительность | Ложные тревоги/ч | Латентность, медиана |
|---|---|---|---|---|
| оффлайн | A (threshold 0.4, ≥5 эпох) | 0.94 | 8.94 | 9 с |
| оффлайн | B (0.4, ≥30) | 0.71 | 0.91 | 6 с |
| real-time | A (0.3, ≥15) | 0.90 | 4.00 | 21 с |
| real-time | B (0.4, ≥30) | 0.71 | 0.87 | 35 с |
| *сравнение:* пороговый детектор, оффлайн | дефолт | 0.86 | 9.45 | 6.5 с |
| *сравнение:* пороговый монитор | дефолт | 0.81 | 4.13 | 23 с |

**Точность событий (precision) в точке A:** ≈ 9% оффлайн, ≈ 14% real-time — большинство
событий ложные; калиброванная уверенность это отражает (ECE 0.015 / 0.048,
кросс-валидация по пациентам).

**Проверка на новых пациентах (пре-регистрирована):** см. раздел 8.

## 5. Известные ограничения и режимы отказа

* **Короткие приступы** (< ~20 с) и **низкоамплитудные фокальные** выявляются хуже
  (LOSO: chb14 3/8, chb16 4/10, chb13 7/12).
* **Артефактные записи взрослых** дают больше ложных тревог (LOSO: PN16 6.8/ч,
  PN05 4.8/ч).
* **Прогрев 30 с** в начале потока (инициализация базовой линии); приступ, начавшийся
  в первые секунды мониторинга, может быть принят за базовую линию.
* **Длительные приступы выявляются не на всём протяжении** (измерено на обучающих
  данных, LOSO, точка A, 8 приступов > 2 мин): покрытие длительности приступа
  детекциями ≈ 0.9 в первых двух третях и **0.46 в последней трети**; самый длинный
  (chb11, 752 с): 1.00 → 0.61 → 0.32. Вероятные причины — адаптация базовой линии
  канала (τ ≈ 5 мин) и физиологическое замедление поздней фазы приступа. Начало
  приступа выявляется; для оценки эпилептического статуса критическая находка (§10)
  опирается на накопленную длительность событий, которая может быть занижена.
* **Билатеральные тонико-клонические приступы** (Siena PN10, тип отсутствует в обучении):
  обученный монитор нашёл 5/10 (v2), пороговый — 8/10; оффлайн 8/10 у обоих.
* **Младенцы:** короткие приступы chb06 (12–20 с) выявляются (оффлайн 9/10, монитор 7/10),
  но с повышенными ложными тревогами (v2: 7.6/ч оффлайн, 6.1/ч в мониторе); у chb10
  (инкремент 10) v1 давал 27/ч оффлайн.
* Не проверено: неонатальные записи, иные монтажи, иные приборы/частоты дискретизации
  вне 256/512 Гц, педиатрические и взрослые популяции вне двух баз.
* Морфологические признаки (line length, энергия Тигера), самокалибровка под пациента и
  «замороженная» базовая линия проверены и **не приняты** — не улучшили выявление при
  кросс-валидации (`docs/learned_detector.md` §11, §12, §14; последняя повышает
  покрытие конца длинных приступов 0.46 → 0.71 ценой общей чувствительности).

## 6. Меры безопасности в системе

* Режим A по умолчанию: каждое событие требует проверки врачом; гейт режима B не
  пропускает автономные решения при низкой калиброванной уверенности.
* Критические находки (§10) и судорожная нагрузка вычисляются независимо от LLM.
* Включение по умолчанию — **только** по пре-регистрированному правилу
  (`configs/ml.yaml`, `evaluation/prereg10/prereg11.apply_decision`); пороговый детектор
  остаётся доступным (`learned=False`).
* Целостность модели: SHA-256 проверяется при пре-регистрированной оценке; модель — JSON
  без исполняемого кода.
* Аудит и деидентификация API (§12, §14) действуют без изменений.

## 7. Воспроизводимость

Все числа воспроизводятся командами из репозитория: загрузка данных (`neurolens
physionet fetch`, SHA-256), внутренняя проверка (`neurolens.evaluation.ml`), заморозка
(`docs/preregistration_increment10_frozen.json`), проверка на новых пациентах
(`neurolens ml-eval --assess`), график (`examples/ml_operating_curves.py`).
