# Пре-регистрация, инкремент 15: обученный детектор интериктальных эпилептиформных разрядов (NMT-Events)

> Зафиксировано и опубликовано **до** загрузки ЭЭГ тестовой части. На момент коммита на диске
> только обучающая часть (184 записи) и CSV-разметка всех записей (метки, без сигналов —
> по ним только посчитаны объёмы частей, как и в инкрементах 12–14).

## 1. Вопрос

Детектор разрядов (спайки, острые волны, спайк-волна) был единственным из основных детекторов,
не проверенным на размеченных реальных данных (`docs/performance_summary.md`, §5). Первая проверка
на обучающей части показала, что эвристический `SpikeDetector` практически непригоден: при
настройке по умолчанию (z = 6) — около 1 660 ложных детекций в час нормальной ЭЭГ, а при самой
строгой настройке (z = 30) — 43 ложных/ч при чувствительности 0.04. Вопрос инкремента:
**даёт ли обученный оконный детектор на людях, не участвовавших в обучении, клинически
приемлемый компромисс «найденные разряды / ложные метки»?**

## 2. Данные

NMT-Events (Alqarni et al., Zenodo 10.5281/zenodo.21630052, CC BY 4.0): 1 075 рутинных ЭЭГ
(Равалпинди, Пакистан; Contec KT88-2400, 200 Гц, 21 канал с референтом A1/A2, ~17 мин), 962
нормальных и 113 аномальных; для аномальных — CSV с началом/концом события, каналами и
комментарием. Архив читается по HTTP-диапазонам: загружаются только нужные файлы,
каждый проверяется по CRC-32 из каталога zip (`datasets/nmt_events.py`).

* **Эпилептиформные события** — комментарий содержит «spike», «sharp» или «poly» (спайк-волна,
  острая и медленная волна, острые волны, полиспайки); **замедление** — «delta (slow) waves».
* **Единицы.** В заголовке EDF указано «uV», но робастный разброс отфильтрованной ЭЭГ ≈ 0.17
  (у бодрствующего взрослого 10–30 мкВ); ошибки единиц десятичны, только ×100 даёт
  физиологичный уровень. Отсчёты трактуются как единицы по 10 мкВ (`AMPLITUDE_SCALE = 100`),
  решено по нормальным записям обучающей части без разметки (D43). Пайплайн теперь сам
  помечает такие файлы и закрывает режим B (`amplitude_implausible`).
* **Разбиение (правило зафиксировано в коде до анализа ЭЭГ, `split_by_rule`):** аномальные —
  чётный номер → обучение, нечётный → тест; нормальные — номер mod 8 = 0 → обучение,
  mod 8 = 1 → тест (остальные не используются, ограничение диска и времени загрузки).
  Одна запись = один человек (в наборе нет повторных записей; номера уникальны).

| Часть | Аномальных | из них с эпилептиформными | Эпилептиформных аннотаций | Нормальных |
|---|---|---|---|---|
| обучение | 64 | 50 | 3 835 | 120 |
| **тест** | **49** | **37** | **2 910** | **119** |

## 3. Эталон и метрики (`evaluation/ied_eval.py`)

* Эпилептиформные аннотации записи по всем каналам объединяются в **события-разряды**, если
  перекрываются или отстоят < 0.25 с (`MERGE_GAP_S`).
* **Чувствительность** — доля событий-разрядов, перекрытых детекцией, расширенной на ±0.25 с
  (`TOL_S`), суммарно по записям; 95% ДИ — бутстреп по записям (2 000 повторов); также макро
  (среднее по записям) и по типу разряда (по исходным аннотациям).
* **Ложных в час** — все детекции в **нормальных** записях / их длительность. В аномальных
  полнота разметки неизвестна, поэтому детекции вне аннотаций сообщаются как «неразмеченные»,
  а не как ложные.
* **Попадания в замедление** — доля событий «delta slow waves» (не перекрывающихся с
  эпилептиформными), задетых детекцией.

## 4. Детекторы (заморожены)

* **Обученный** — `configs/models/ied_gbm_v1.json`,
  sha256 `2f9754f90be86e36cfb45ebea90d66e95da90d1c9b8419677eefa6c82fc47abf`
  (`layer4_detect/ied_ml.py`): окна 0.5 с с шагом 0.25 с на 19 электродах 10-20 (средний
  референт после фильтров пайплайна); амплитуда, крутизна, острота, длина линии, последующая
  дельта-волна, доля 20–70 Гц — относительно фона канала за запись и окружения ±5 с; агрегаты по
  каналам, индекс доминирования лобно-полюсных (моргания), соседние окна (195 признаков);
  градиентный бустинг (sklearn, экспорт в JSON). Обучен на всех 184 записях обучающей части.
* **Порог 0.95** — выбран кросс-валидацией на обучающей части (5 групповых фолдов по записям):
  максимальная чувствительность при ≤ **15 ложных/ч** нормальной ЭЭГ (`FA_BUDGET_PER_H`; одна
  ложная метка в 4 мин — ≈ 5 меток для просмотра в 20-минутной рутинной ЭЭГ). Бюджет выбран
  после просмотра кривой кросс-валидации обучающей части (тестовые данные не загружались).
* **Эвристический** `SpikeDetector` — без ограничения числа событий, по сетке z
  4…30 (`HEURISTIC_Z_GRID`), пики по всем каналам в пределах 0.25 с — одна детекция.

Кросс-валидация на обучающей части (`docs/preregistration_increment15_frozen.json`):

| Детектор | Чувствительность (95% ДИ) | Макро | Ложных/ч | Попаданий в замедление |
|---|---|---|---|---|
| обученный, порог 0.95 | 0.639 (0.47–0.77) | 0.623 | 12.8 | 0.289 |
| обученный, порог 0.85 | 0.818 | 0.791 | 39.7 | 0.463 |
| эвристический z = 6 (по умолчанию) | 0.952 | 0.925 | 1 663 | 0.573 |
| эвристический z = 30 | 0.039 | 0.114 | 43.5 | 0.008 |

## 5. Гипотезы (тестовая часть; `evaluation/prereg15.py`)

* **H1** — чувствительность обученного детектора при пороге 0.95 ≥ **0.50**.
* **H2** — ложных/ч в нормальных тестовых записях ≤ **22.5** (бюджет 15 × 1.5).
* **H3** — обученный детектор доминирует над кривой эвристического: ни одна точка сетки z не
  имеет одновременно не меньшей чувствительности и не большей частоты ложных.
* **H4** (вторичная) — попаданий в замедление ≤ **0.40**.

## 6. Правило решения (применяется кодом `prereg15.apply_decision`)

* **H1 ∧ H2 ∧ H3** → `configs/ied.yaml`: `enabled: true`, модель и порог выше; в отчёте событие
  «спайк» даёт обученный детектор (не для новорождённых — они в наборе не представлены).
* Иначе → `enabled: false`: остаётся эвристический детектор, в сводке он помечается как
  непроверенный/непригодный по результатам этого инкремента.
* H4 и разбивки по типу разряда — только для отчёта, на решение не влияют.


## 8. Ограничения, известные заранее

* Один центр, один прибор, южноазиатская популяция; заявленный диапазон 6–93 лет расходится с
  CSV (есть 8 месяцев, 1–3 года).
* Разметка — один набор аннотаций (число экспертов в описании не указано), полнота неизвестна.
* Рутинная ЭЭГ бодрствования; сон, ОРИТ и длительный мониторинг не представлены.
* Поправка единиц ×100 выведена из уровня сигнала, а не из документации набора.
