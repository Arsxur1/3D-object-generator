# Пре-регистрация: инкремент 13 — стадирование сна (AASM) на Sleep-EDF

> Зафиксировано в git **до загрузки любых записей тестовой половины**. Разбиение, эталон,
> признаки, модель, гипотезы, правило решения и код анализа (`evaluation/prereg13.py`) не
> меняются после получения результатов; замороженная модель и оценка кросс-валидации
> развивающей половины добавляются в раздел «Заморожено» до загрузки теста. До этого
> коммита загружена одна ночь развивающей половины (SC4001) — для проверки чтения.

## Вопрос

ТЗ (слой 4) предусматривает стадирование сна; в NeuroLens его не было. Может ли обученный
стадировщик по двум ЭЭГ-отведениям и ЭОГ надёжно размечать стадии W/N1/N2/N3/REM у новых
людей, чтобы показывать гипнограмму и показатели сна в отчёте?

## Данные

Sleep-EDF Expanded (PhysioNet sleep-edfx 1.0.0), часть sleep-cassette: 153 ночные
полисомнографии 78 здоровых испытуемых 25–101 лет, гипнограммы экспертов (R&K, эпохи 30 с).
Целостность — SHA-256 PhysioNet. Отведения: EEG Fpz-Cz, EEG Pz-Oz, EOG horizontal (100 Гц).

## Эталон и окно анализа (зафиксировано, `datasets/sleepedf.py`)

* R&K → AASM: стадии 3 и 4 → N3; «?» и «Movement time» не оцениваются.
* Окно: от 30 мин до первой эпохи сна до 30 мин после последней.

## Разбиение (зафиксировано)

По номеру испытуемого: чётный — развивающая половина (40 испытуемых, 78 ночей), нечётный —
тестовая (38 испытуемых, 75 ночей).

## Стадировщик (обучение только на развивающей половине)

* Признаки эпохи (`layer4_detect/sleep_staging.py`): для Fpz-Cz и Pz-Oz — лог-мощность,
  абсолютные и относительные мощности в 6 полосах (0.5–2, 2–4, 4–8, 8–12, 12–16, 16–30 Гц),
  спектральная энтропия, SEF95, параметры Хьорта, отношения полос; для ЭОГ — мощность
  0.3–2 и 2–8 Гц и дисперсия. Стандартизация по ночи (медиана/IQR), контекст ±2 эпохи.
* Модель — многоклассовый градиентный бустинг (200 итераций, 31 лист, balanced,
  random_state 0), JSON, предсказание numpy (совпадение со scikit-learn — тест).
* Внутренняя оценка — 5-кратная кросс-валидация с группировкой по испытуемому (фолд =
  номер испытуемого mod 5); финальная модель — на всей развивающей половине.
* Сравнение — правиловый стадировщик без обучения (`rule_based_stages`).

## Метрики

Эпохальные по всем тестовым ночам: каппа Коэна (первичная), точность, макро-F1, F1 по
стадиям, матрица ошибок; медиана каппы по ночам.

```bash
neurolens sleep fetch --split test
neurolens sleep eval --split test --frozen docs/preregistration_increment13_frozen.json \
  --assess --out out_eval/prereg13
```

## Гипотезы

* **H1 (первичная):** каппа обученного стадировщика на тесте ≥ 0.70.
* **H2:** каппа обученного ≥ каппы правилового + 0.10.
* **H3 (перенос):** |каппа теста − каппа кросс-валидации развивающей половины| ≤ 0.05.
* **H4:** макро-F1 ≥ 0.65.

## Правило решения

Стадирование включается в отчёт по умолчанию (`configs/sleep.yaml enabled: true`) — для
записей ≥ 2 ч с электродами для производных Fpz-Cz / Pz-Oz (из 10-20: среднее Fp1/Fp2 − Cz,
Pz − среднее O1/O2; ЭОГ — канал ЭОГ или F7−F8) — **если верны H1 и H2**; иначе остаётся
выключенным (опция). Применение — `prereg13.apply_decision`. H3 и H4 — вторичные.

Оговорка, известная заранее: модель обучается на полисомнографии здоровых взрослых; перенос на
клинические 10-20 записи (другие производные, пациенты ОРИТ, седация) этой проверкой **не**
оценивается и будет указан как ограничение.
